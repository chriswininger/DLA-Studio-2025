# 3D DLA Simulation

A 3D extension of the 2D Diffusion-Limited Aggregation simulation, rendered with Three.js via `@react-three/fiber`.

## Overview

Walkers are spawned as spheres within a configurable bounding sphere and perform a random walk in 3D space. When a walker drifts within the configured stick distance of any cluster point, it becomes part of the cluster. A line is drawn between each newly stuck particle and the cluster node it attached to, producing a branching tree structure.

The simulation seeds a single stuck point at the origin and confines all walkers within a bounding box (default half-extent of 8 units).

## Controls

- **Particles to Spawn** -- number of walkers to create on each spawn action
- **Spawn Sphere Radius** -- radius of the sphere within which new walkers are randomly placed
- **Stick Distance** -- how close a walker must be to an existing cluster point to stick (larger values produce denser, bushier structures; smaller values produce thinner branches)
- **Start / Stop** -- run or pause the random walk simulation
- **Reset** -- clear all walkers and cluster, re-seed the origin point

The 3D viewport supports orbit controls (click-drag to rotate, scroll to zoom).

## Architecture

- **`dla-3d.ts`** -- simulation engine: `createDLA3DState`, `stepDLA3D`, types (`Point3D`, `ClusterEntry3D`, `ClusterMap3D`, `DLA3DState`)
- **`three-dimensional-dla-slice.ts`** -- Redux state for UI controls and persisted simulation data
- **`three-dimensional-dla.tsx`** -- main page component with the Three.js canvas and simulation loop
- **`sphere-spawn-controls/`** -- spawn parameter inputs (particle count, radius)
- **`simulation-controls/`** -- simulation parameter inputs (stick distance)
- **`three-dimensional-dla-constants.ts`** -- defaults and buffer limits

## Performance

Rendering uses `InstancedMesh` for both walkers and cluster spheres, and a pre-allocated `BufferGeometry` for connection lines. All position and color updates happen imperatively inside `useFrame` with no React state changes during simulation, matching the approach used by the 2D canvas renderer.
